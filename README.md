# Music Streaming App

A responsive music streaming app inspired by Spotify, built with modern web technologies to deliver a smooth and intuitive listening experience.

## Features

* Responsive and modern UI
* Home page with music sections and playlists
* Music player with play/pause and track controls
* Audio playback support
* Reusable components for scalable UI
* Styled with a clean Spotify-like theme
* Mobile-friendly design

## Tech Stack

* **Frontend:** React.js
* **Language:** JavaScript
* **Styling:** Tailwind CSS

## Getting Started

### Prerequisites

* Node.js installed
* npm or yarn installed

### Installation

```bash
git clone https://github.com/Yuvraj-Kathad/Spotify-clone.git
cd spotify-clone
npm install
npm start
```

## Available Scripts

In the project directory, you can run:

```bash
npm start
npm run build
npm test
```

## Usage

1. Open the app in your browser.
2. Browse available songs or playlists.
3. Click play to start listening.
4. Use the player controls to manage playback.
